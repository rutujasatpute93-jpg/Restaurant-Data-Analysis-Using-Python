# Restaurant Data Analysis Using Python

## Project Description
This project analyzes restaurant data using Python libraries to understand restaurant ratings, costs, locations, customer votes, and online delivery availability.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
- Analyze restaurant distribution by city.
- Explore restaurant ratings and average costs.
- Identify highly rated restaurants.
- Study the relationship between votes and ratings.
- Visualize online delivery availability.

## Visualizations
- Bar Chart: Top 10 cities by restaurant count
- Histogram: Restaurant rating distribution
- Histogram: Average cost distribution
- Scatter Plot: Ratings vs Votes
- Pie Chart: Online delivery availability

## Skills Demonstrated
Data Cleaning, Data Analysis, Exploratory Data Analysis (EDA), NumPy, Pandas, and Data Visualization.


## Conclusion
This project demonstrates how Python libraries can be used to analyze restaurant data and generate meaningful insights through data visualization.

**Environment:** Google Colab
